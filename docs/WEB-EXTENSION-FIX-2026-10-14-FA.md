# اصلاح افزونه نسخه وب — ۱۴ اکتبر ۲۰۲۶

## علت خطای نسخه قبلی

نسخه 3.0.0 افزونه **فقط آدرس HTTPS** را از فیلد دستی می‌پذیرفت، ولی پیش‌نمایش توسعه با دستور `npm run preview:web` روی `http://127.0.0.1:3000` اجرا می‌شود. بنابراین در این حالت، اتصال با همان افزونه قابل آزمایش نبود. این طراحی همچنین خطر اشتباه‌تایپ کردن دامنه مشتری را افزایش می‌داد.

## تغییر نسخه 3.1.0

- **فیلد واردکردن آدرس حذف شد.** افزونه آدرس نصب BilitFast را فقط از تب فعال مرورگر می‌گیرد؛ آدرس قبلی ذخیره یا بازیابی نمی‌شود.
- برای استقرارهای مشتری فقط **دامنه HTTPS** مجاز است؛ آدرس ناامن اینترنتی پذیرفته نمی‌شود.
- فقط برای **تست روی همین کامپیوتر** `http://localhost:3000` یا `http://127.0.0.1:3000` مجاز است. پورت‌های دیگر، IPهای شبکه و نسخه‌های قدیمی دسکتاپ مجاز نیستند.
- افزونه برای ارسال کوکی اجازه دامنه انتخاب‌شده را **در پاسخ به کلیک کاربر** درخواست می‌کند. درخواست اجازه پیش از عملیات غیرهمگام آغاز می‌شود تا حالت user gesture حفظ شود.
- پیش از دسترسی به کوکی سفیر ریل، سلامت `/api/cookie-sync` روی همان مقصد بررسی می‌شود. پاسخ غیر JSON یا قطع ارتباط با متن دقیق‌تری گزارش می‌شود.
- کوکی‌ها تنها پس از **کلیک مستقیم** و ارائه **کد جفت‌سازی یک‌بارمصرف** از همان پروفایل مرورگر خوانده و ارسال می‌شوند.
- سمت BilitFast اعتبار ورود عمومی و اعتبار مجوز رزرو جداگانه بررسی می‌شوند؛ «تحویل موفق کوکی» مساوی «رزرو موفق» نیست.

## اجرای تست محلی

1. در ریشه پروژه `npm ci` و سپس `npm run preview:web` اجرا کنید. آدرس **`http://127.0.0.1:3000/login.html`** را در Chrome باز کنید. **تست محلی فقط برای توسعه است، نه فروش.**
2. افزونه قدیمی BilitFast را غیرفعال کنید. در `chrome://extensions` حالت Developer mode را روشن کنید، Load unpacked را بزنید و **پوشه `extension` همین سورس** را انتخاب کنید. نسخه افزونه باید **3.1.0** باشد.
3. در همان پروفایل Chrome/Edge، تب `https://safirrail.ir/etrain/index.php` را باز کنید و با حساب مجاز خود وارد شوید.
4. به **تب BilitFast** برگردید؛ اگر لازم است اول به حساب BilitFast وارد شوید. دکمه «اتصال به سفیر ریل» را بزنید و کد شش‌رقمی را دریافت کنید.
5. در حالی که **تب BilitFast فعال است** آیکون افزونه را بزنید؛ باید آدرس همین تب را نمایش دهد. کد را وارد و روی «تأیید و ارسال نشست» کلیک کنید. مجوز دسترسی به دامنه نمایش‌داده‌شده را فقط اگر آدرس متعلق به خودتان است قبول کنید.
6. پیام نهایی ورود را **در صفحه BilitFast** بررسی کنید. افزونه فقط تحویل کوکی را گزارش می‌کند، نه پذیرش نشست توسط سفیر ریل.

تست‌های بدون دسترسی به سفیر ریل:

```powershell
.\scripts\Test-BilitFastWebExtension.ps1 -FullSuite
```

## خطاهای رایج

- **«افزونه را در تب BilitFast باز کنید»**: موقع کلیک روی افزونه، تب اصلی BilitFast فعال نبوده است.
- **«ارتباط با سرویس BilitFast برقرار نشد»**: برنامه روی آدرس انتخاب‌شده در حال اجرا نیست یا مجوز Chrome صادر نشده است.
- **«این آدرس نسخه سازگار ... ندارد»**: افزونه به نسخه قدیمی یا سایت دیگری وصل شده است.
- **«کد جفت‌سازی نامعتبر یا منقضی»**: کد تازه‌ای از همان تب وب بگیرید؛ اعتبار کد حدود دو دقیقه است.
- **«نشست رزرو پیدا نشد»**: در همان پروفایل مرورگر وارد بخش رزرو سفیر ریل شوید؛ فقط باز بودن صفحه اصلی کافی نیست.
- **«نشست تحویل داده شد» اما BilitFast ورود را رد می‌کند**: انتقال کوکی انجام شده اما سرور سفیر ریل ممکن است نشست را وابسته به IP، مرورگر یا تأیید ARCaptcha بداند. این محدودیت با تغییر UI افزونه حذف نمی‌شود.

## امنیت و محدودیت

کوکی نشست معادل دسترسی حساب کاربر است. آن را در چت، لاگ عمومی یا برای پشتیبانی ارسال نکنید. هر سرور مقصد باید متعلق به مشتری و قابل اعتماد باشد؛ بسته توسعه، اصالت مالک دامنه را با گواهی ویژه فروشنده اثبات نمی‌کند. برای اجرای تجاریِ کاملاً قابل‌اتکا، اتصال رسمی و مجاز سفیر ریل بهتر از ارسال نشست مرورگر به یک سرور دوردست است. **تست واقعی Chrome/Edge + سایت سفیر ریل در این محیط انجام نشده** و تایید عملی باید روی سیستم دارنده حساب صورت گیرد.
