# BilitFast Web 3.12.0 — رزرو در تب جدید با حفظ برنامه

در هنگام انتخاب «انتخاب و تأیید ربات» در صفحه `route.html`، افزونه یک تب **جدید** در همان پنجره Chrome/Edge باز می‌کند. تب اصلی BilitFast، جستجوها و اطلاعات مسافر بدون تغییر باقی می‌مانند.

**جریان:**
1. تب BilitFast را باز نگه دارید؛ پس از اتصال یک‌باره افزونه به نصب معتبر، قطار را انتخاب کنید.
2. افزونه یک تب خالی موقت باز می‌کند؛ سپس فقط پس از ذخیره‌سازی موقت اطلاعات معتبرِ همان رزرو، به `https://safirrail.ir/etrain/index.php` می‌رود و فرم رزرو رسمی را از دامنه سفیر ریل ارسال می‌کند.
3. کاربر چک‌باکس واقعی ARCaptcha را شخصاً تأیید می‌کند. ادامه اطلاعات مسافر/واگن فقط در صورت تطابق با انتخاب قبلی و امکان شناسایی کنترل رسمی صورت می‌گیرد. پرداخت بانکی خودکار نیست.
4. اگر سایت رزرو خطا داد یا باز نشد، با انتخاب تب BilitFast برگردید و قطار را دوباره انتخاب کنید. کلید «بازگشت به تب BilitFast» در پنل کناری نیز در دسترس است.

**محدودیت‌ها و امنیت:** این تغییر کپچا را به دامنه BilitFast منتقل نمی‌کند و هیچ توکن جعلی/دستی ایجاد نمی‌کند. کوکی‌های رسمی توسط Chrome در مبدأ safirrail.ir استفاده می‌شوند؛ نشست منتقل‌شده به BilitFast تضمین ورود معتبر روی سایت اصلی نیست. درخواست و اطلاعات مسافر برای تب رزرو جدید (`siteTabId`) مقیدند؛ یک تب دیگر اجازه استفاده از داده آن رزرو را ندارد. اطلاعات حساس در URL یا لاگ نوشته نمی‌شوند. برنامه برای انجام عملیات رزرو نیازمند اینترنت است.

**آزمون‌ها:** `npm run test:new-tab`، `npm run test:official-handoff`، `npm test`. سپس در Chrome واقعی با افزونه 3.12.0 و Refresh کردن تب BilitFast تست کنید. در تست زنده موفقیت واقعی کپچا، ظرفیت و درگاه تضمین نشده است.
