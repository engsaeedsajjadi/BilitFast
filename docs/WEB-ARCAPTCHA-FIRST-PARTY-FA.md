# بازیابی مسیر رزرو با ARCaptcha — نسخه وب / افزونه 3.2.0

## چرا مدل قدیمی دیگر جواب نمی‌دهد؟
نسخه قدیمی، تصویر کپچای عددی را از پاسخ رزرو دریافت و به‌صورت محلی تحلیل می‌کرد و با یک درخواست دیگر به فرم مسافر می‌رسید. نسخه جدید سفیر ریل در HTML فرم `div.arcaptcha[data-site-key]` و `input[name="arcaptcha-token"]` دارد. این فیلد باید توسط سرویس رسمی ضدربات و در مرورگر کاربر تأیید شود. نمایش صرف یک چک‌باکسِ مشابه داخل دامنه BilitFast نه معادل آن تأیید است، نه توکن قابل‌قبول می‌سازد.

## جریان فعلی
۱. مرورگر Chrome/Edge مشتری: یک تب BilitFast و یک تب سفیر ریل که کاربر قبلاً وارد حساب رزرو خودش شده است.
۲. در BilitFast قطار و اطلاعات مسافران انتخاب شود؛ وقتی API پاسخ `arcaptcha_required` داد، یک `browserHandoff` شامل آدرس ثابت `https://safirrail.ir/etrain/TresV-auth.php` و فیلدهای شروع رزرو آماده می‌شود.
۳. **در همان تب مسیر BilitFast** افزونه نسخه 3.2.0 باز شود؛ روی «شروع تأیید رزرو در سفیر ریل» کلیک شود.
۴. افزونه پس از بررسی مبدأ، شناسه سرویس، داشتن فرم مسافر و یکسان‌بودن پروفایل دو تب، از **داخل تب رسمی سفیر ریل** فرم را با `POST` ارسال می‌کند. به‌این‌ترتیب کوکی مرورگر در همان سایت اعمال می‌شود. این عمل با ارسال HTTP از سرور مشتری یا یک cross-site POST متفاوت است.
۵. کاربر ARCaptcha را **خودش** روی سایت رسمی تأیید می‌کند؛ افزونه هیچ رویداد کلیک روی ویجت و هیچ توکن مصنوعی ایجاد نمی‌کند.
۶. پس از رفتن سایت به فرم مسافر، افزونه در صورت تشخیص فیلدهای `pid0,ruz0,mah0,sal0,fn0,ln0` آنها را با داده‌ای که کاربر موقع شروع در اختیار افزونه گذاشته است، پر می‌کند و نتیجه را نشان می‌دهد.
۷. کاربر باید همه مشخصات، قطار و مبلغ را بررسی کند و دکمه تأیید سایت را خودش بزند. انتقال به پرداخت و دریافت بلیت فقط با پاسخ واقعی سامانه قطعی می‌شود؛ BilitFast نباید موفقیت کاذب نمایش دهد.

## حریم خصوصی و امنیت
- مقصد شروع رزرو فقط HTTPS /etrain/TresV-auth.php روی safirrail.ir است.
- اطلاعات مسافر در `chrome.storage.session` موقت نگه داشته شده و پس از مصرف پاک می‌شوند؛ پس از ۱۵ دقیقه دیگر تحویل داده نمی‌شوند. هیچ توکن کپچا یا اطلاعات بانکی در افزونه ذخیره نمی‌شود.
- برای استقرار مشتری، دامنه BilitFast باید HTTPS باشد؛ فقط پیش‌نمایش localhost/127.0.0.1 روی پورت 3000 مجاز است.
- نباید دو پروفایل یا دو حساب متفاوت برای تب BilitFast و سفیر ریل انتخاب شوند.
- افزونه محتوای صفحات رسمی را فقط با مجوز کاربر و فقط روی دامنه safirrail.ir تغییر می‌دهد.

## تست ویندوز
از ریشه ZIP جدید:

```powershell
npm ci
npm run test:official-handoff
npm test
npm run preview:web
```

افزونه قبلی را غیرفعال و پوشه `extension` این نسخه را با Chrome/Edge > Extensions > Developer mode > Load unpacked بارگذاری کنید. **آزمایش پذیرش ARCaptcha، انتقال به فرم مسافر و پرداخت واقعی صرفاً با حساب مجاز در مرورگر واقعی قابل تأیید است.**

## محدودیت مهم
این یک گردش‌کار یکپارچه در مرورگر است، **نه** قراردادن مجدد ویجت امنیتی ARCaptcha در DOM وب‌اپلیکیشن مشتری. انتقال ویجت به دامنه BilitFast، بدون پشتیبانی رسمی ارائه‌دهنده، ممکن است به‌دلیل وابستگی دامنه/نشست و سیاست‌های امنیتی نامعتبر شود. اگر سایت در آینده فیلدهای فرم یا جریان POST را تغییر دهد، باید adapter سازگار به‌روزرسانی شود.
